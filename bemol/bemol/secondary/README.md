
# Secondary correction models

`hubTipLoss.py`: hub/tip loss correction.

`dynamicInflow.py`: dynamic inflow correction.

`skewAngle.py`: skew angle correction.

`turbulentWakeState.py`: turbulent wake state correction.

`yawModel.py`: yaw models.

In order to implement a new model, go to the corresponding file and add
a new class similar to the ones already present.
